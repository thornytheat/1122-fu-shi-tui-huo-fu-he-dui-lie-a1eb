# 服饰退货复核队列

值班仓管按日结前包裹扫描排队验包。样例是合成退货授权、称重、异店转送和历史验包标签，保留扫描修订、面单跨店、虚假体重和历史未结单据。每个退款授权最多派发一个复核位。容量单位为当班最多可以受理几件包裹，默认九件。

按「门店称重设备 × 商品组」拟合经营历史中的绝对称重偏差中位数，下限保留该台称量设备的误差。称重设备台账登记每台秤的服役区间（安装日、退役日、设备误差下限）：换秤后旧设备立即退役，其历史样本保留在旧设备编号下，永远不会进入新设备的分组。新设备的某商品组历史样本不足最小样本量时不做自动估计，仅登记设备误差下限并把包裹转人工核验，不借用其他门店、其他设备或全局样本兜底。重新派件时使用该时点可见的退款历史，结算截止后的称重不进入基线。模型是带 L2 的四维逻辑回归，标签按结单时间切分，前三四分之三用于训练、末段用于保序校准；训练向量与在线评分由同一条特征代码、同一版本基线（`baseline_id`）生成。训练域外物件、开封包裹和设备基线不足的包裹进入人工待核，超过原门店配额仍保留审理队列。金额整数单位为分，页面将其换算为元。

历史阈值复盘仅计算已完成验包记录。平均精确率按同分组聚合，未发现错件的窗口显示不可计算。该历史样本无法评估未被复核退货的真实错件率。曲线显示各个阈值下会漏掉的退款金额。

### 称重设备台账

顶层 `scales` 列表，每个服役区间一行：

- `shop` 类型 `str`，门店编号。
- `scale` 类型 `str`，物理称重设备编号，同门店内不得重复。
- `installed_at` 类型 `int`，设备安装日（含当日）。
- `retired_at` 类型 `int` 或 `null`，退役日（不含当日）；同一门店的服役区间不得重叠。
- `instrument_floor` 类型 `float`，有效范围 0–1，该台设备的最小可读误差，也是样本不足时唯一允许采用的容忍度下限。

## 终审与预算证据

验包回测滑动验证点分别锁定训练、校准和后验窗口，展示类别校准差与拒绝原因。复核位试算输出各门店待核份额、已占用名额和未覆盖本金，并标注当前容量成本下的方案前沿。退款台账用原门店加授权单号对账，重复载货标签、金额差异和复核位冲突保留独立原因。试算建议并未调用支付系统。
